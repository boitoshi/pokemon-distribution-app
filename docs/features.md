## 検索トップ（`src/pages/index.astro`）

目的の配信へすぐ届くことを優先し、大きな Hero や説明文は置かない。

1. **キーワード検索**: ポケモン名・配信名・親名など。複数語可、ひらがな／カタカナを区別しない
2. **期限が近い配信**: 受取期間内で終了が近いものを上に出す
3. **条件を選んで探す**:
   - 期間の状態（全件／期限間近／受取期間内／期限未設定／終了／開始前）
   - 受取先ゲーム・配信方法・地域・並び順・色違いのみ
   - 詳細な条件（開閉式）: 世代・開始日の範囲・ボール・親名・トレーナーID・キョダイマックス・オヤブン・特別な技・持ち物・リボン／あかし（複数選択・いずれか／すべて）
   - 結果は24件ずつ「もっと見る」で追加。カードから個別ページ（`/pokemon/[id]`）へ

### 新UIへの切り替えで外した機能（2026-09-27 ユーザー判断）

| 機能 | 扱い |
|---|---|
| お気に入り・所持チェック・メモ・所持率（コレクション統計）・検索条件の保存 | **廃止の方向**。localStorage の既存データ（`pokemon-favorites` / `pokemon-owned` 等）は消していない。タイムラインは同じキーを引き続き読む |
| 比較 | 残したい。見せ方を検討してから戻す |
| タイムラインへの導線 | 残したい。見せ方を検討してから戻す（`/timeline` 自体は公開したまま） |
| まとめページへのリンク帯（`src/data/gen-guides.json`） | 要検討。JSON は残してあり、トップからは参照していない |
| URLパラメータで条件を開く（`?shiny=1&ribbon=…`） | 要検討 |
| ダークモード切替・統計ダッシュボード・スマホ下部の固定絞り込みボタン | 未判断 |

`src/components/SearchBox.astro` と `PokemonCard.astro` は旧UI専用で、現在どのページからも使っていない（`scripts/lint-project.mjs` が SearchBox の存在を必須にしているため残している）。

### データ関連（pokemon-data 側の作業）
- [ ] **specialMoves（特別な技）の追補（手動確認枠）** — 2026-08-03 時点で計60件記録済み（第8・9世代19件の正本復元 + 第6世代34件・第7世代7件のイベント限定技〔おいわい/てをつなぐ/ハッピータイム〕機械抽出）。残るのは機械検出できない「本来覚えない技」パターン（第8世代の「ちきゅうなげリザードン」相当）の手動洗い出し。第5世代はイベント限定技の該当なし（おいわい等の登場は第6世代から）
- [x] Championsの検索対象への追加 — 対応済み(2026-08-03)。Champions(generation:0・21件)を検索UI・タイムラインの対象に含める（世代フィルタで「Champions」として選択可能）。個別ページ・summary-pagesへのリンク帯は従来通り

  - **設計決定(2026-08-04・ADR 0013): `distributions/home.json` は新設しない**。2026-08-03 の「独立ファイル（ID は HM 系）」案は撤回した。理由は、`distributions/schema.json` が「generation はファイル自身が表す（L3ビルドが注入）」と定めているため、独立ファイルにすると Champions と同じ `generation: 0` 扱いになり、**世代フィルターで HOME配信がヒットしなくなる**こと。利用側の要件は逆（第8世代以降のフィルターで HOME配信もヒットしてほしい）。正本: `../pokebros-content-hub/docs/adr/0013-home-distributions-placement.md`
  - 配置基準: 受取先ソフトが特定できる配信（連携記念・ソフト図鑑完成記念）はそのソフトの世代へ。HOME内で完結する配信（バインダー作成記念ピチュー / GTS交換成立記念ロトム / 全国図鑑完成記念マギアナ 等）は HOME ローンチ世代の gen8 へ置く（**便宜上の割り当て**であって「第8世代の配信」の意味ではない）
  - 表示設計(2026-08-03、有効): HOME受取でも受け取り先ソフトが特定できる配信（SV/剣盾等に着地）はそのソフト・世代で表示。HOME内のみ（どのソフトにも移動していない/HOMEアイコンの個体）は Champions と同様に世代兼ソフト「HOME」の1行表示とする
